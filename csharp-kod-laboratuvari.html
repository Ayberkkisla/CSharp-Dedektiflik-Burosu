ÇÖZÜMLÜ ÖRNEK · ÇİFT NUMARALI DOSYALAR

1’den 6’ya kadar çift sayıların toplamı

2 + 4 + 6 = 12. Sayıyı % 2 ile kontrol ediyoruz. Kalan 0 ise toplamın üstüne ekliyoruz.

Kullanılan parçalar ne işe yarıyor?
int toplam = 0;
Sonucu biriktireceğimiz tam sayı kutusunu oluşturur. Henüz dosya yok, başlangıç 0.
for (int i = 1; i <= n; i++)
i, 1’den başlar. i ≤ n olduğu sürece döngü çalışır. Her turun sonunda i++ sayıyı bir artırır. Üst sınır n de hesaba katılır.
if (i % 2 == 0)
% bölme işleminden kalanı verir. 2’ye bölümden kalan 0 ise sayı çifttir. == iki değeri karşılaştırır.
toplam += i;
toplam = toplam + i ile aynıdır. Önceki toplamın üstüne o sayıyı ekler.
return toplam;
Biriken sonucu fonksiyonu çağıran yere gönderir; fonksiyon biter.
{ } ve ;
Süslü parantezler döngünün ve koşulun hangi satırları kapsadığını belirler. Noktalı virgül atama ve return gibi ifadeleri bitirir.
