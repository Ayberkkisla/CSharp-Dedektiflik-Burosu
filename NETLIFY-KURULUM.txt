DEDEKTİF NOKTA — NETLIFY KURULUMU

GitHub bağlantılı dağıtımda Netlify, npm run build komutunu çalıştırır ve kök klasörü yayınlar.
Google girişi için Netlify ortam değişkenlerine NOIR_FIREBASE_CONFIG ekle.
Değer, firebase-config.example.js içindeki nesnenin kendi proje değerlerinle doldurulmuş geçerli JSON karşılığı olmalıdır.
Ortam değişkeni tanımlı değilse Google girişi kapalı kalır; misafir ilerlemesi cihazda saklanır.

Manuel dağıtımda önce npm run build çalıştır. Üretilen assets/firebase-config.js dahil klasörü yükle.
Firebase yapılandırmasını Git'e ekleme. Ayrıntılar README.md dosyasındadır.
